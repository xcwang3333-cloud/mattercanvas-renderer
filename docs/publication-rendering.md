# Publication Rendering Workflow

## Camera presets

- publicationIso: default DFT structure figure
- top: slab top view
- side: surface/interface view

## Export

Recommended:

- scale = 3-4 for high resolution PNG
- transparent background for figure assembly
- fixed camera preset for comparing adsorption structures

Example:

PbN4
PbN4-COOH
PbN4-OCHO
PbN4-CO

should share the same camera and style settings.
