# MatterCanvas Renderer v0.4.17 Release Candidate

## Overview

This release candidate consolidates the publication figure workflow:

VASP structure files → analysis → publication rendering → export.

## Validation Targets

### PbN4 CO2RR

Validated workflow:

- PbN4
- *COOH
- *OCHO
- *CO

Rendering features:

- active Pb center highlight
- coordination annotation
- multi-panel comparison

### LnFe ORR

Validated workflow:

- Ln-Fe heteronuclear site
- coordination environment display
- publication camera presets

## CI Scope

Release candidate checks cover:

- structure import
- renderer modules
- export workflow
- demo manifests

## Export Formats

- SVG vector figure
- PNG preview
- PDF publication output
